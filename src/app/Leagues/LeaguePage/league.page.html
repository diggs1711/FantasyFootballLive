You will need either your FPL Id or the League Id to see your leagues.

 FPL ID

Your FPL Id can be found in the url when you select the points tab at https://fantasy.premierleague.com/. This will add all the leagues you are entered in at once.

LEAGUE ID

The league Id can be found in the url when viewing the league standings eg. https://fantasy.premierleague.com/a/leagues/standings/ League ID /classic

ADDING A LEAGUE
